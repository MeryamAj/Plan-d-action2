findIndex() et some() répondent à trois besoins différents.

find() : its method will search insid of the array and it will return the first element for which the callback function returns a true the value if it dosen't find then it will return undifined.


findIndex() : its method loops through an array to find and return the index of the first item in the array that meets a specified condition, it returns -1 if it doesn't find any item that meets the condition.



some() : its method it returns true if it finds an element that satisfies the provided function otherwise if the iterator is exhausted without finding such an element it returns false .
